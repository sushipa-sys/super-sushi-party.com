## 1. 前提 / 世界観

- **主語**：SUPER SUSHI PARTY = アニメーションユニット（あべゆうか × 松本伊代）。
- **マーティーたちの位置づけ**：SSPの世界の「住人 / 最初の住人」。
  ユニット＝親、マーティーのキャラクターブランド＝最初のプロジェクト。将来 新住人・押絵キャラ等を「新しい住人」として増やせる構造。

- **ベンチマーク**：POLA「すべてのお母さんに、ありがとう。」= 1セクション＝1画面の没入スクロール型。

## 2. ページの置きどころ（全体設計）

- **独立ページ `about.html` として作成**。TOP内の1セクションには押し込まない。
- 既存 `information.html` の「**TOP共通ヘッダー・フッター ＋ 独立ページ**」パターンを踏襲する。
- ヘッダー / フッター / ナビ / ダークモード / スムーススクロール / モバイルメニューは **TOP（index.html）共通を流用**。
- TOP側の既存ABOUTセクションは、いずれ「数行ティザー ＋ 『ABOUTへ →』リンク」に差し替える想定（TOPは既存のため、本作業のスコープ外／別途）。
- 配置：`/www/about.html`。CSSは既存 `style.css` を流用し必要分のみ追記。JSは既存 `script.js` を流用。

## 4. 実装メモ（Claude Code向け）

- **共通パーツ移植**：header / footer / nav / dark mode toggle / mobile menu / smooth scroll / scroll spy を `index.html` から移植。
- **既存クラス流用候補**：`intro-content` / `info-container` / `news-grid`・`news-card` / `modal`（`#newsModal`）など。
- **演出実装**：`IntersectionObserver` で各セクション・各行のフェードイン。全画面セクション（`100vh`）＋必要に応じて scroll-snap。
- **改行厳守**：コピーの `<br>` 位置は動かさない（改行＝デザイン）。
- **フォント / テーマ**：既存フォント（Bebas Neue 等）流用。ダークモードのCSS変数に対応させる。
- **OGP / favicon**：`information.html` のパターンに合わせる。**相対パスに注意**（`information.html` は `../` 参照。`about.html` を `/www/` 直下に置くならパス階層を合わせて調整）。
